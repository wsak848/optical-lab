# Optical Communication Laboratory

ห้องทดลองจำลองการสื่อสารทางแสงสำหรับการเรียนรู้ด้วย Streamlit

## Lab 1: ความถี่และความยาวคลื่นของแสง

ปรับความยาวคลื่นตั้งแต่ 400 ถึง 1700 nm เพื่อดูความถี่ที่คำนวณจาก `f = c / λ` และการเปลี่ยนระยะห่างของคลื่นในภาพจำลอง ค่าความเร็วแสงที่ใช้คือ `3.0 × 10^8 m/s` เริ่มต้นที่ 1310 nm และมีปุ่มเลือก 850, 1310 และ 1550 nm

ความยาวคลื่นอ้างอิงสุญญากาศ เมื่อแสงเข้าสู่ใยแก้ว ความเร็วและความยาวคลื่นเปลี่ยนตามดัชนีหักเห แต่ความถี่คงเดิม ภาพคลื่นเป็นภาพนิ่งเชิงแนวคิด: แนวนอนคือระยะทางสัมพัทธ์ แนวตั้งคือแอมพลิจูดมาตรฐาน ไม่ใช่กำลังแสงหรือระยะทางการแพร่จริง และสีเส้นไม่ใช่สีแสง

ผู้สอน: Sakda Wongadyarin

## Lab 2: ดัชนีหักเหและความเร็วแสงในตัวกลาง

เลือกบททดลองจากเมนูด้านบน โดย Lab 1 และ Lab 2 เก็บผลการทดลองแยกกันในเซสชัน
Lab 2 มีแท็บทฤษฎี ตารางดัชนีหักเห การทดลองและบันทึกผล และสรุปผล
ใช้สูตร `v = c / n` โดย `c = 3.0 × 10^8 m/s` กับอากาศ (1.0003), น้ำ (1.333), Acrylic / PMMA (1.49), Fused Silica (1.458) และเพชร (2.4168)
ค่าดัชนีหักเหเป็นค่าอ้างอิงโดยประมาณเพื่อการศึกษา และขึ้นอยู่กับวัสดุและความยาวคลื่น

นักศึกษาคำนวณและส่งคำตอบตัวกลางละหนึ่งครั้ง รวม 5 ครั้ง จึงเปิดเผยความเร็วอ้างอิง ผลต่าง และ Error ของตัวกลางนั้น ยอมรับ Error ไม่เกิน 0.5% และแก้คำตอบเดิมได้โดยไม่เพิ่มจำนวนครั้ง
สรุปผลแสดงจำนวนครั้งที่ส่งคำตอบ จำนวนคำตอบถูก Error เฉลี่ย ตารางผล และความเร็วเป็นเปอร์เซ็นต์ของ c เฉพาะตัวกลางที่ส่งคำตอบแล้ว พร้อมคำถามวิเคราะห์ 5 ข้อ
ตารางเลื่อนแนวนอนได้บนมือถือ ปุ่มเริ่มใหม่ล้างเฉพาะ Lab 2 ข้อมูลไม่ถูกบันทึกถาวร

## Lab 3: กำลังแสง dB, dBm และการลดทอนในใยแก้วนำแสง

เลือก Lab 3 จากเมนูเดิม มีแท็บทฤษฎี ทบทวน dB/dBm, Simulation, การทดลองและบันทึกผล และสรุปผล
ใช้ `P(dBm) = 10 log10(PmW)`, `PmW = 10^(P(dBm)/10)`, `Loss = alpha × Length` และ `Pout = Pin - Loss` โดยเน้น `0 dBm = 1 mW`

ส่วนที่ 1 คำนวณ dBm จาก 0.1, 0.5, 1, 2 และ 10 mW ส่วนที่ 2 ใช้ Pin = 0 dBm และ alpha = 0.20 dB/km ที่ระยะ 1, 5, 10, 15 และ 20 km ต้องส่งทั้ง Loss และ Pout จึงตรวจผลและเปิดเผยค่าอ้างอิงเฉพาะข้อนั้น
ใช้ผลต่างสัมบูรณ์ไม่เกิน 0.1 dB ไม่ใช้เปอร์เซ็นต์บน dBm ส่วนที่ 2 ต้องถูกทั้งสองค่าจึงนับว่าถูก ส่งซ้ำแทนคำตอบเดิม

Simulation ปรับ Pin ระยะทาง และ alpha ได้ พร้อมกราฟ Output Power (dBm) เทียบกับระยะทาง และแสดงกำลังขาออกทั้ง dBm และ mW
โปรไฟล์ 850 nm / Multimode (3.0 dB/km), 1310 nm / Single-mode (0.35 dB/km) และ 1550 nm / Single-mode (0.20 dB/km) เป็น **ค่าตัวอย่างสำหรับการเรียนรู้** เท่านั้น ค่าจริงขึ้นอยู่กับชนิดใยแก้ว wavelength ผู้ผลิต สภาพสาย connectors, splices และปัจจัยอื่น แบบจำลองคิดเฉพาะการลดทอนในเนื้อใยแก้ว

สรุปผลรวม 10 ครั้ง แสดงจำนวนที่ส่ง จำนวนถูก และค่าเฉลี่ยผลต่างสัมบูรณ์ของคำตอบ dBm ล่าสุด พร้อมตารางทั้งสองส่วนและคำตอบวิเคราะห์ 6 ข้อ ผลและคำตอบวิเคราะห์เก็บในเซสชันแยกจาก Lab 1–2 และคงอยู่เมื่อสลับ Lab ตารางเลื่อนภายในได้บนมือถือ Lab 3 ใช้พื้น navy/black โดยคงรูปแบบ Lab เดิม

## เริ่มใช้งาน

แนะนำ Python 3.13 (ทดสอบด้วย Python 3.13.2) และ virtual environment แยกสำหรับโครงการ
คำสั่งสำหรับ Windows PowerShell โดยเรียก Python ใน environment โดยตรง ไม่จำเป็นต้อง activate:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

เปิด URL ที่ Streamlit แสดงใน terminal (โดยทั่วไปคือ http://localhost:8501) กด Ctrl+C เพื่อหยุด
Dependencies หลักมีเพียง Streamlit, NumPy และ Matplotlib โดยกำหนดช่วงเวอร์ชันที่เข้ากันได้ใน `requirements.txt`
